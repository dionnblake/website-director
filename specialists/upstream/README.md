# Pinned upstream snapshots

Seven upstream repositories are represented here by local, read-only provenance manifests. Each manifest records the exact commit, license, inventory timestamp, skill count, and license text. The complete `SKILL.md` path and blob inventory is in `../config/skill-inventory.json`.

The snapshots are intentionally not executable. Raw upstream orchestration, package installation, publishing, deployment, and specialist recursion are inert. Website Director selects normalized adapters under its own authority.
